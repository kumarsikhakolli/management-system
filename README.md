# TownMart 🛒
React local e-commerce and shop-management project.

Features: Amazon/Flipkart-inspired UI, customer login/register, products, search, categories, cart, checkout, UPI QR placeholder + UTR, orders, admin product/stock management, manual payment verification, and a TownMart information chatbot.

Run with npm install && npm run dev.

Admin demo: admin / admin123.

This learning version uses localStorage. UPI payments are not automatically verified; admin manually accepts/rejects after checking the UTR.
